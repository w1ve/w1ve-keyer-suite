This Player advertises itself on the LAN. Choose it from W1VE Remote Keyer or W1VE Remote Keyer Router.

Keying status

Network: —

KEY: Up

PTT: Off

Only authenticated current-plus-history CW edge frames can drive KEY/PTT. The selected Keyer repeats its latest complete frame; the Player imposes a 1500 ms lease on asserted KEY. Configured GPIO outputs and the optional white LED confirm accepted keying.

GPIO keying output

RGB status LED

Red: no Wi-Fi. Green: paired. White: accepted key-down. GPIO 48 is the generic ESP32-S3 default.

Radio connections

Use transistor, optocoupler, or a rated relay interface between the ESP32 GPIO and radio KEY/PTT inputs. Do not connect a radio key line directly to an ESP32 pin.

LAN Player discovery

The W1VE ESP32 Player advertises itself only on its joined home Wi-Fi station subnet. The setup access point remains for configuration but cannot discover, pair, or carry raw W1VE keying. On a W1VE Remote Keyer or W1VE Remote Keyer Router, choose this Player from the available Player list. WAN pairing is not supported by this Player.

KEY and PTT safety

W1VE ESP32 Player accepts only endpoint-pinned, session-verified CW frames. The selected Keyer repeats its latest complete frame for loss recovery. The Player imposes a 1500 ms lease on asserted KEY and releases KEY/PTT on unpair, missed frame refresh, or local configuration change. Configured GPIO outputs and the optional white LED confirm accepted activity.
