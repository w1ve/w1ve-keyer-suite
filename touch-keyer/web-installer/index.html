W1VE Touch Keyer

Flash the Touch Keyer firmware to a Waveshare ESP32-C6-Touch-LCD-1.47 board directly from your browser.

Your browser can't talk to USB serial devices. Open this page in Chrome or Edge on a desktop computer.

ESP32-C6-Touch-LCD-1.47 (8 MB)

The Waveshare board this firmware targets.

How to flash

  1. Connect the board to this computer with a USB data cable.
  2. Click Install.
  3. Choose the board's serial port in the browser prompt. If no port appears, hold BOOT, tap RESET, release BOOT, then try again.
  4. Let the flash finish. The board reboots into the setup access point W1VE-Keyer (password w1vekeyer, address 192.168.4.1), where you join it to your Wi-Fi.

A fresh install erases the chip, including any saved Wi-Fi, pairing code and WireGuard identity.
